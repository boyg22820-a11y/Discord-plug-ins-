# Changelog

## 0.3.0

- Add virtual folders, multiple tags, destination selection during mixed photo/video import, and ordered/pinned batches.
- Add optional guarded + media-menu interception, original-menu escape, and runtime capability status.
- Add conservative confirmed-send tracking with upload nonce/server message correlation; do not infer historical sends.
- Add pinned collections, Recent, bulk edits, session Undo, persistent trash, repair and storage totals.
- Add native SHA-256 with bounded JavaScript fallback, exact-content deduplication and reversible duplicate merging.
- Persist browsing state independently for DMs/server channels.
- Add metadata/full multipart backups, checksum validation, merge restore, large original-media sharing and hash-based relinking.
- Split editable source into model/platform/UI modules and expand tests.
- Preserve 0.2.0 saved collection metadata during migration. On-device verification remains required.

## 0.2.0

Custom Quick Photos collection with imports, private-copy or temporary fallback, favorites, filename search, adjustable columns, multi-select and Files/command shortcuts.

## 0.1.1–0.1.2

Compatibility diagnostics and targeted API capture. Superseded by the custom collection.
